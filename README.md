# Project Overview
Built a end-to-end data application powering operations for a smoothie shop by integrating Snowflake, Streamlit, and REST APIs. The project progresses from foundational database architecting to interactive UI application development:

- Snowflake Database Architecture: Designed and built a multi-tiered Snowflake database environment, defining custom schemas and structured tables to support application data modeling.
- Interactive Streamlit Applications: Developed user-facing applications in Python using Streamlit, starting with simple menu rendering and expanding to full-featured order management interfaces.
- External API Integration: Connected application logic to external REST APIs to dynamically pull real-time data into the Streamlit interface.
- Modern Data Stack Connectivity: Established direct, secure connections between Streamlit and Snowflake to query, update, and manage data live within the user interface.

## Tech Stack
- Database & Data Warehouse: Snowflake (SQL)
- Application Framework: Streamlit
- Language: Python
- Integrations: REST APIs
